A FEW THINGS TO KNOW

开始之前，
你可能想知道。

需要懂技术，或者另外装软件吗？＋

不需要配置运行环境。下载电脑对应的安装包，按提示安装即可。安装完成后，桌面会自动创建快捷方式；使用时双击打开。

为什么打开后是在浏览器里？＋

桌面图标负责启动你电脑上的工作台，操作界面显示在浏览器里。像打开普通软件一样双击图标即可，不需要自己记网址。浏览器关闭后，仍可再次双击图标回到工作台。

我的 LibTV 账号会交给别人吗？＋

你在 LibTV 官方页面登录并确认授权。当前只申请账号读取权限，授权信息加密保存在你的电脑上；下载服务器不接收你的 LibTV 授权。你也可以在工作台移除连接。

现在能直接生成图片或视频吗？＋

当前是连接体验版，已开放账号连接与个人、团队空间选择。图像和视频生成尚未开放，安装这个版本不会发起付费生成。

下载安装遇到提示，或者打不开怎么办？＋

请先核对电脑类型：Windows 版适用于 64 位 Windows 10 / 11，Mac 版适用于 Apple 芯片（M 系列）。当前 Windows 版未签名，Mac 版未完成 Apple 公证；若浏览器或系统阻止安装，请把提示截图发给交付人员核对，不要关闭系统安全防护。安装完成后请从桌面「资产实验室」图标启动。

以后如何更新？卸载会丢掉资料吗？＋

当前还没有自动更新。后续版本发布后，可回到本页下载安装；安装前先在工作台底部点击「退出本地工作台」。程序和资料分开保存。Windows 卸载程序、或在 Mac 移除应用时，都不会主动删除独立保存的项目及账号连接。

让工作台，在桌面等你。

安装完成后，双击「资产实验室」开始连接。
