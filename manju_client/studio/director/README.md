# 探查神体 · 大师兄导演台

新增六镜头导演设计：顶部“导演新版 / 改版前”可切换比较并分别保存。设计见 [导演设计-v2.md](导演设计-v2.md)，可导入工程为 [探查神体-导演设计版.json](探查神体-导演设计版.json)。

15 秒、6 镜头、可编辑的 Three.js 白模预演。基于已有府邸正堂几何，人物以带关节的彩色简模表示。当前用于构图、走位、运镜和镜头切换，不是最终漫剧视频。

## 打开

工作区地址： http://127.0.0.1:8768/dashixiong-scene-studio/director/index.html

独立使用时从父目录启动 HTTP 服务，再打开 `/director/index.html`，不能用 file://。

## 使用

### 一键套用镜头手法

1. 先在左侧分镜列表或底部时间轴选一个镜头。
2. 在上方“镜头手法库”选择拍法、拍摄对象；可展开调整全景/中景/近景、运动幅度、左右或上下方向。
3. 点“套用并预演”，摄影机会按人物位置和当前画幅生成轨迹，自动进入摄影机视角，只播放当前镜头并在末尾停下。勾选“循环本镜头”可以连续比较。
4. 点“空间总览”或“俯视布置”查看摄影机轨迹、方向和人物关系；点“重播本镜头”重新观看实际构图。
5. 不满意可换拍法再套用，或“撤回上次套用”。每次套用只替换当前镜头的机位、注视点、焦距与运动节奏。

现有 15 种：固定、缓慢推进、拉远揭示、横向移镜、水平摇镜、上下摇镜、垂直升降、弧线环绕、360° 完整环绕、跟随人物、光学变焦、推拉变焦、双人关系机位、越肩看叶宇、越肩看师心水。

适合先试：S01 双人中景 + 弧线环绕；S05 叶宇 + 推拉变焦；S06 师心水 + 跟随人物。跟拍使用人物实际的起身和退避轨迹；摇镜固定摄影机位置，横移会移动摄影机，光学变焦只改变焦距，推拉变焦会联动距离与焦距。

预设的选择、轨迹和参数随工程保存、导出、导入。移动人物或切换画幅后会提醒重新套用；已有镜头不会被悄悄重算。“撤回上次套用”只保留本次打开页面中该镜头的最近一次套用备份，刷新后不可用；需要长期留版本请导出工程。

### 空间编辑与工程

1. 点击播放，观看 0–15 秒预演；空格暂停，左右方向键逐帧。
2. 空间总览查看摄影机，俯视布置查看走位，代入摄影机查看构图；右侧监看始终为拍摄镜头。
3. 选择摄影机位置、注视点或人物，再拖动三维箭头；也可填 XYZ。角色位置应用于整段。
4. 选择镜头起点、终点或时间轴位置，编辑坐标与焦距；在中间时刻编辑会添加关键帧。橙线表示当前镜头的摄影机轨迹。
5. 选择 16:9、9:16、21:9。画幅作用于整段摄影机，但三种画幅仍需分别检查构图，不自动重排人物和机位。
6. 展开“这镜头为什么这样拍”查看用途、衔接与研究来源；青色轴线提供侧别提醒，不禁止有意跨轴。
7. 自动保存仅限当前浏览器和当前来源网址；跨机器请导出 JSON 工程，PNG 按所选画幅重新渲染。

## 初始镜头

0–2s 双人关系与伸手；2–4s 手部接触；4–7s 主观星脉穿行；7–10s 神祇体量揭示；10–12s 叶宇近景；12–15s 抽手起身退避。

## 边界

- 人物身体比例、场景尺寸和动作均为预演估计值。没有最终角色皮肤、精细表情、布料模拟、口型或音频。
- 异象片场用抽象图形确定镜头，尚未完成神祇美术设计。
- 目前没有视频生成接口，也没有 MP4 导出；本轮没有调用付费生图或视频模型。
- 工程 JSON 包含机位、注视点、焦距、关键帧和角色位置。网页简模和动作由代码重建，尚未导出为可交换的角色动画文件。
- 现阶段可以编辑既定六镜的机位；不能新增/删除镜头或修改片长。
- 首镜机位侧别是轴线提醒的参照；不自动审查遮挡、碰撞、光线、视线、动作匹配或镜头叙事。
- 预设根据人物位置、身高、动作与画幅估算机位，不是自动避障求解器。完整环绕可能跨轴或穿过家具，需要实际查看轨迹。异象镜头不提供人物跟随、双人及越肩机位。
- 预设轨迹采用采样关键帧记录，界面默认显示起点、中点和终点，可展开全部关键帧继续微调；手动改动会标记“已手动调整”。
