## 画布优化

- `frame-renderer.js` 合并同一帧中的交互绘制，制作画布与导演画布共用；状态先更新，绘制下一帧执行，松手时立即应用最终位置。
- `story-canvas.js` 在平移、缩放时只更新画布变换和缩放标签。卡片移动、尺寸变化或内容刷新时才重新计算几何与连线；尺寸集中读取，避免逐条边交错读写布局。
- 布局保存使用一个防抖计时器；切换项目、关闭页面和卸载时保存各自待保存的布局，包括尚未绘制的最后位置。绘制帧、观察器和监听随卸载释放。
- `frontend/package.json` 声明独立 ES module 边界，避免测试运行时沿父目录财税项目的配置反复推断模块类型；没有新增第三方依赖。
