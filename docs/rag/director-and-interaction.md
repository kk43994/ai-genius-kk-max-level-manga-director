# 导演编排与页面交互

状态：0.3.0-preview.1 已实现；真实浏览器合成场景已验证点击引用、拖入第二镜头与保存。不是生成质量或客户验收结论。

## 视图

主导航仅保留剧本分析、风格探索、资产制作、导演编排、审核交付。MJ 候选只在风格页；Image2 与 Nano 在资产内部切换。候选图旁选用直接记录人工作出的审核决定，放大和具体修改意见仍可使用。

Image2 默认制作要求按物料类别生成：角色正面全身、侧面全身、背面全身、头部特写；场景正视、反打、俯视、侧面；道具白底正视。默认资产画幅与影片画幅分开，用户可修改。四视图是否实际正确由人看图确认，按钮名称不构成图像质量验收。

## 引用

导演台左侧显示已审核资产；搜索、点击或拖入中间镜头，固定 assetId、stateId、revisionId。错误场次、失效图片、跨原账号或未审核图片不能引用。文字里的 `{{asset:id}}` 存储稳定编号，界面显示可点击名称。删除仍被描述使用的引用会被阻止。

拖拽用指针事件及目标元素位置命中，避免浏览器原生图片拖拽吞掉落点；键盘仍可点击引用。原方案与人工修改分开，保存时带版本检查，发生冲突保留本机草稿。

## 草稿与任务

boardgen 与 art-direction 草稿已加入服务端白名单，和 production 草稿一起参与服务器确认与升级保护。后台刷新仅替换候选图与任务反馈，不替换正在编辑的表单。任务中心新增返回图片与档案定位入口；恢复仍查询原任务。

规范资产经人工审核即可下载；Nano 精修可选。当前方案的全部物料与分镜通过审核后才能确认完成并归档，详见 [交付范围](delivery-scope.md)。最终视频仍暂停，图板预演只展示参考和台词。

代码：`frontend/workflow/creator-desk.js`、`production-generation.js`、`production-board.js`、`controller.js`、`scripts/browser/bootstrap.mjs`、`backend/integration_drafts.py`。

## 前端实测后的编辑补齐（2026-11-01）

制作方案核对是直接可见的按钮；点击画布卡片后，外层详情保持展开。风格页发现原文问题时可直接返回对应核对界面。手工补充后，清单摘要使用当前草稿数量。

`shot-structure.js` 提供用户主动触发的拆镜和加镜：按原台词 ID 一句一镜，首镜保留 ID，新镜使用新 ID，原文、事件和引用不丢失，顺序重新连续编号。新增空动作镜不重复对白。对白时长按每秒约四字加停顿给出编辑建议，不是配音或自动验收。拆出的镜头继承原设计作为草稿，必须逐镜调整动作、构图和连续性，保存仍使用原版本冲突与原文检查。

真实 Chrome 前端已完成引用修正、补充道具、拆镜、逐镜修改与保存，未新增文本模型调用。真实出图及图文导出仍在继续；源内容只在外部验收实例保存。
# 操作错误与后台通知

当前操作错误或本机保存错误必须持续显示，后台图片返回通知不得覆盖错误正文和恢复按钮。用户开始下一次操作或主动刷新后再清除；`controller.js` 的 `announce` 仅在没有当前错误时更新状态区域。
