# 画布内看图与修改

适用：0.3.0-preview.6 源码开发版；公共安装包仍为 preview.5。状态：功能已实现，真实既有项目交互已核验；新收费生成与客户审美签收另行验收。

## 已确认方向

发现问题的位置就是修改入口。用户批准 1–8、10：点图工具栏、卡片文字编辑、可见参考、补素材返回原镜、原位任务与候选、前后镜连续审片、常用参数记忆、多镜共同要求、替换前影响范围。圈选局部重绘不在本轮范围。

## 使用与约束

- 点当前或历史图打开修改/重抽、Nano、版本比较工具栏；历史图可查看但失效依据不会自动绕过。候选点选仍是人工决定。
- 镜头侧栏同时放当前图、目的、动作、构图、角色台词和参考。上一/下一镜保留草稿；键盘切镜仅在审片面板非输入区域生效。
- 人工改写台词写到该镜 `dialogueOverrides`，保留关联原文和 `origin=manual`。分析模型不能伪造该字段。导出同时保留原句与改写；调整台词不会篡改剧本事实。
- 参考始终固定具体版本；只对唯一明确的已选图片补齐草稿，已有指定版本不替换。历史引用显示原图与待核对提示，不能自动作为当前有效参考。
- 从镜头进入素材，保留镜头位置和草稿。用户选好图后点击“用于原镜头并返回”；有歧义时回原镜点图选择。
- 任务进度和新候选原位更新，保留输入。未知或失败任务只恢复原回执，不自动再计费。
- 模型、比例、数量、分辨率等偏好按项目/账号/空间/阶段隔离；不复制主体提示词、参考、种子或任务幂等编号。
- 多镜共同要求先展示所选范围，再加入这些镜头草稿。批量新版本只提交明确勾选且参考有效、没有未决回执的镜头，原图保留。
- 更换已选资产先展示直接及间接依赖；确认全剧标准前也可查看受影响图片。任何此类操作都不自动重抽。

## 代码与验收

- `frontend/workflow/in-place.js`、`in-place.css`：就地审片、参考、参数、共同要求、影响预览。
- `controller.js`：镜头上下文/草稿/局部反馈/费用确认、补素材返回。
- `version-picker.js`、`production-generation.js`、`storyboard-overview.js`：图片工具栏与历史图可见。
- `backend/analysis/production.py`、`production_review.py`、`storyboard_export.py`：人工台词覆盖及来源保存。
- `tests/workflow/in-place.test.mjs`、`tests/analysis/test_dialogue_overrides.py`：隔离参数、歧义引用、批量原子性、依赖影响、台词安全。
- [逐项清单](../plans/2026-11-03-in-place-creation.md)记录真实 Chrome 范围和限制。合成开发用例只证明实现行为；真实验收使用用户指定既有项目，私有内容不入库。

## 恢复

本次无需数据库结构迁移。撤回本迭代源码前先备份实例数据，保留已存的台词覆盖/草稿字段与原任务；旧版本不认识新字段时不得强行重存覆盖。公共安装包不随源码提交改变。
