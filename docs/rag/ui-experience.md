# 前端体验与组件规范

日期：2026-11-03。范围：preview.6 本地开发源码。用户要求现代、简约、有质感，重点是按钮、输入框、文案、合适的组件与动效，最终改善使用体验。

## 设计与实现

- 石墨灰背景、低对比结构线、蓝灰选中态。普通按钮 38 px，紧凑工具 32 px，主要创作入口 44 px；触屏控件适当增大。选图、画布拖动与生成确认仍采用原有业务语义。
- 原生 button / input / select / textarea / details 组成统一组件层。导入剧本改为真实按钮触发文件选择，可用 Enter 操作；图标按钮有可访问名称和悬停说明。更多菜单可用 Escape 关闭，关闭编辑面板恢复到重绘后的原操作按钮。
- 名称、标题等短字段改成单行输入，已有多行内容继续使用文本框以保留原值。剧情、台词、提示词保留多行编辑。常用画幅、张数、分辨率直接可见，其余模型参数折叠；表单仍从同一官方 schema 提交参数。
- 新建项目精简重复介绍；画布工具栏将提示词规范、定位待处理和自动排列收进更多菜单。费用、失败、来源变化和人工审核提示保留。
- 面板在窄屏近全屏展示，工具栏换行；移动端打开面板时隐藏悬浮任务入口，避免遮住保存或生成按钮。任务记录仍由原模块保存和显示。
- Lucide 1.66.0 按需保留本地图标；GSAP 3.15.0 为本地分发。只在面板打开或页面切换时做 160–200 ms 过渡，轮询和输入不重新播放，遵循 prefers-reduced-motion。不依赖外部 CDN。

代码：`frontend/ui/studio-ui.js`、`studio-ui.css`、`icons.js` 与 `vendor/`。控制器显式挂载、等待样式后测量画布、卸载清理。MutationObserver 只增强新增节点，不监听平移缩放属性；不增加请求、保存或审核动作。第三方许可随公开构建保留。
