# 迭代、版本与恢复约定

状态：本轮开始执行。更新时间：2026-11-01。

- 优化前运行源码基线为 `a8a3437`，叠加原工作区 22 个已存在改动保存为 `7329c2f`。开发在独立 worktree 的 `codex/creator-workflow`，不覆盖原运行目录。
- GitHub 使用项目私有仓库。main 作为可恢复基线，功能分支分别提交后提出 PR。没有验收的版本保持预览标识，不自动合并、部署或发布安装包。
- 每个有意义的功能提交同时更新 CHANGELOG、对应 RAG 主题和版本状态。标签只绑定真实提交，不移动已发布标签。
- 版本记录包含需求、实现状态、测试命令／结果、浏览器验收、已知问题、数据变更与恢复步骤。未执行的检查明确写未执行。
- 版本升级沿用语义版本：功能为 minor，修复为 patch；本轮候选为 0.3.0-preview.3。GitHub 源码版本、运行版本、安装包版本分别核对，推送成功不等于用户已升级。
- 回退前保存外置数据库与文件的一致备份及对应加密密钥保管关系，检查 schema 兼容性。此轮关联为项目字段的增量扩展，无物理删除；旧程序读不到新关联不等于数据丢失。不得在运行中 git reset 原工作区或覆盖数据库。

知识维护不收集客户剧本、客户图片、OAuth token、Cookie、密码或私有账号标识。版本测试使用合成数据；本地路径和原始截图只保存在外置验收目录。
