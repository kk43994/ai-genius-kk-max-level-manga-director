# 迭代、版本与恢复约定

状态：持续执行。更新时间：2026-11-03。

## 每次升级必须登记

[升级时间线](../updates/README.md) 是“这次更新了什么”的入口；功能专题说明当前行为，两者分别维护。同一个 preview 版本中的每次改动也各有记录，不再只往一份长版本说明里堆内容。

每次代码提交同时新增 `docs/updates/YYYYMMDD-HHMM-name.md`，按 [模板](../updates/TEMPLATE.md) 填写：用户遇到的问题、具体前后变化、实际检查及未验证范围、源码/安装包/设备升级状态、实现和功能资料链接。新记录的提交号由 Git 首次加入记录的提交确定；旧记录回填使用完整真实提交号。

运行 `python scripts/check_update_history.py --render` 同时更新 GitHub RAG 首页的最近八次具体变化与完整列表，`python scripts/query_project_knowledge.py --updates --limit 5` 查询最近升级。`--updates --version 0.3.0-preview.6` 查看指定版本内每次改动。CI 使用完整 Git 历史，程序、测试、构建或检查脚本提交漏记升级时会失败；RAG 检查同时核对记录必填内容、重复标识和目录是否同步。该检查只保证记录齐全，不代替真实验证。
