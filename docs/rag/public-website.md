## 内容与结构

KK DIRECTOR 是面向漫剧工作室的 AI 导演台；当前通过 LibTV 扩展使用用户的创作能力与额度，Lovart 为后续规划。官网以用户确认的黑曜石与复古金色胶卷主图为核心，和 README 共用品牌主图；流程区使用原创四联概念图。展示平台接入、五阶段制作、人工编辑、下载、近期升级与 RAG 入口。概念图不冒充软件截图。

## 视觉与运镜

`local_client/website/stage.js` 使用 SVG 与原生脚本：全景开场 → 滚动推近人物 → 八边光圈收拢进入章节。主图局部裁切层轻微错速移动，曲线边缘扫光与指针视差增加层次；这是图像的 2.5D 演绎，不是可自由旋转的三维胶卷模型。保持同一张已确认主图，不自动换人或换风格。无音频、无 Three.js 依赖。

手机使用独立近景裁切，确保面部和主体金属边缘可见；支持暂停和系统 `prefers-reduced-motion`，后台不持续更新画面，浏览器返回可恢复动画。正文用深色底承接，导航有遮罩以免与正文重叠。修改后检查开场、中段推近、光圈转场、手机裁切及下载可用性。品牌生成提示词记录在 `docs/brand/PROMPTS.md`。

旧 ManjuWorkbench 场景/白模实验版保留原下载，收进说明折叠区，避免和当前主线混淆。主线安装后的图标仍为“资产实验室”，页面明确提示，未修改现有安装包品牌或伪造新版。

## 同一渲染器，分别核对版本

`scripts/build_download_site.py` 的完整发布流程和 `--published-release` 网页更新模式均调用 `render_site`。源码版本取自 `local_client.APP_VERSION`；下载文件名、版本、大小和 SHA-256 从实际发布清单读取；网站更新时间单独显示。最近三次变化直接读取 `docs/updates`，入口链接完整升级时间线，避免官网重新写一套不一致的日志。

只更新网站时：

```bash
python scripts/build_download_site.py \
  --published-release /path/to/current/release.json \
  --manju-release /path/to/current/manju-release.json \
  --output /path/to/static-candidate
```

此模式只产生 HTML、品牌素材、CSS、交互脚本及 `site-content.json`，不重写 release.json、不重命名旧安装包，也不复制客户数据。上传候选文件覆盖到当前发布目录的副本，核对原文件后原子切换站点指针；保留全部历史下载。新目录里的静态文件使用新文件替换，不能原位覆盖旧发布的硬链接文件。

## 发布检查

每次涉及对外能力或版本的变动，都要检查 GitHub、官网模板和实际网页。公开前对比下载清单与文件哈希、页面所有下载目标和新图片，桌面与 390 px 浏览器验证导航、折叠及可读性。公开后用 HTTPS 检查页面与资源，保留实际发布目录、回退指针和版本差异证据。没有构建新包时明确安装包不变。

本轮 3 项检查覆盖旧下载版本保留、恶意/错误下载路径拒绝、每个平台完整性字段必填，以及统一渲染输出。公开部署结果见逐次记录。

本轮网站已于 2026-11-03 08:58（北京时间）公开发布，13 项 HTTPS 文件校验一致；公共安装包与更新清单保持 preview.5。详情及后续 GitHub 验证见 [本次升级](../updates/20261103-0810-public-website.md)。

## 创作展示与交付内容

2026-11-03 内容迭代：五阶段制作以可点击面板展示，每步固定说明 AI 先做、你来决定、这一步得到；这只是官网介绍，不是把实际工作台锁成线性向导。面板支持鼠标和键盘，JS 不执行时显示完整五步。交付章节使用四联原创概念图说明图文脚本、制作资产与固定参考依据，明确当前聚焦图片创作；不使用用户素材、不把概念图称为产品截图。开始步骤为安装、LibTV 官方授权、导入剧本；模型与素材库范围按图片创作 RAG 核对。见 [内容迭代记录](../updates/20261103-0905-website-storytelling.md)。

品牌标识来源登记于 `docs/brand/THIRD_PARTY_MARKS.md`；LibTV / Lovart 从各自官网导航矢量提取，仅调整单色呈现。当前接入与规划状态不能混用；规划连线不播放流动动画。设备卡片以浏览器平台信息提示系统家族，Mac 必须另提示 Apple 芯片，不推断 CPU，也不自动触发下载。全页动效统一响应固定暂停按钮、系统减少动态效果，持续动画仅在可见时播放。
