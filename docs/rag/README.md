检索优先级：本目录当前条目及版本记录 > 当前代码与测试 > 旧验收文档。旧文档仅描述其记录日期的状态；冲突时查对应提交和实际运行版本，不把旧门槛自动当成当前事实。

检索入口：`python scripts/query_project_knowledge.py "导演 拖拽 固定版本"`。输出来源、适用版本、状态与正文；无外部请求，属于本地关键词检索，不宣称已有语义向量召回。机器索引为 `index.json`；`--check` 校验所有来源路径。
