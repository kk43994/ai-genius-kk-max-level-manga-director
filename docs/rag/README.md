# 漫剧工作台项目知识索引

更新：2026-11-02。适用分支：`codex/creator-workflow`。目标版本：`0.3.0-preview.4`（本地候选版）。

此处维护可检索的项目知识源；不是已经上线的向量检索服务。每个知识条目独立说明决策、代码位置、验证与缺项。客户剧本、素材、账号与凭据不进入知识源。

| 查询主题 | 权威条目 | 主要用途 |
| --- | --- | --- |
| 用户确认的流程、页面归属、按钮 | [创作流程](creator-flow.md) | 判断功能放在哪一步，谁来确认 |
| 旧资产、新状态、图片版本如何关联 | [资产关系](asset-lineage.md) | 避免同名自动合并和素材重复建立 |
| 导演拖入、固定版本、草稿、任务定位 | [导演交互](director-and-interaction.md) | 核对界面行为及对应实现 |
| 可复用提示词、场景四视图、出图审核和失败修正 | [图像提示词规范](image-prompt-standards.md) | 区分待验证、单次通过和重复验证的方法 |
| 当前物料、分镜、归档与历史范围 | [交付范围](delivery-scope.md) | 避免漏算未建档物料或混入闲置旧档案 |
| 分支、提交、版本、回退 | [版本管理](versioning.md) | 每次迭代同步代码、文档、验收 |
| 当前版本实现与缺项 | [0.3.0-preview.3](../versions/0.3.0-preview.3.md) | 防止把规划、测试和交付混为一谈 |

检索优先级：本目录当前条目及版本记录 > 当前代码与测试 > 旧验收文档。旧文档仅描述其记录日期的状态；冲突时查对应提交和实际运行版本，不把旧门槛自动当成当前事实。

检索入口：`python scripts/query_project_knowledge.py "导演 拖拽 固定版本"`。输出来源、适用版本、状态与正文；无外部请求，属于本地关键词检索，不宣称已有语义向量召回。机器索引为 `index.json`；`--check` 校验所有来源路径。
