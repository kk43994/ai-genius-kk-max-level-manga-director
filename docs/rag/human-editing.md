# 固定流程与人工编辑

适用：0.3.0-preview.6 源码开发版。公共安装包仍为 preview.5。

## 用户确认的产品原则

固定的是每部剧通用的制作阶段、字段结构、引用方式和界面布局。角色、场次、事件、台词、镜头及其数量属于创作内容；AI 生成初稿，人能改、增、删、纠错和决定采用。AI 不替人锁定答案。原剧本和原始返回保留作依据，当前创作版本可编辑。看到问题的位置应有修改入口。

## 本次落地

- 画布“编辑剧情”或人物/场次/剧情卡片的修改入口，打开同页侧栏；角色、场次、地点、时间、事件、台词、疑点可新增、修改、删除。别名、外貌、服装、关系和原文引用支持增删。
- 删除分析记录前仅按稳定 ID 展示已建立的关联，不推断删除对剧情合理性的影响，也不声称覆盖自由文字中的全部提及；不静默级联删除其他内容；缺失关联保留为待改选项。删除记录的恢复列表按分析任务隔离保存在本机；服务端继续保留原始结果与人工复核历史。
- 空白台词/引用等未填完的字段可先保存，继续以卡片展示并标示问题，不因空字符串退回只剩 JSON 的界面。缺少对象结构仍用原始内容修复。
- 分镜台词有说话人、类型、正文、新增、删除/恢复、上下排序。可选已有角色或自填说话人。说话人/类型不再是固定文字。
- `dialogueOverrides` 保存对原句的人工改写与删除标记；`dialogueAdditions` 保存人工新增；`dialogueOrder` 保留顺序。原分析台词不被覆盖。显示、系统试读、图文预览、HTML/JSON 导出读取同一份有效台词。
- 正常镜头也可删除；`removedShots` 保存完整内容，`shotOrder` 记录恢复位置。删除不清除图片、回执或原文台词，恢复后保留稳定镜头 ID。新增镜头不会复制上镜的人工台词，拆镜不会丢掉人工改写。
- AI 输出契约不包含人工台词/删除字段；即使模型擅自返回，也不能冒充人工决定。人工删除的镜头不进入当前预演/导出，但原始记录保留。
- 制作方案再次保存时留存上一版人工复核内容。保存仍校验归属、版本冲突、引用完整性；不能以“开放编辑”为由关闭数据保护。

## 验证范围

真实 Chrome 使用用户指定的既有项目：说话人和类型切换、新增台词、排序、删除/恢复、正常镜头删除/恢复、刷新保留草稿；剧情角色新增/删除/恢复和被引用角色的删除前影响提示。390 px 视口无横向溢出。原有制作草稿先暂存后恢复；临时测试内容清除，未保存新剧情到客户方案，未重新分析或收费生成。

服务端保存/再读/导出、原文不变、删除项过滤、归属与冲突及模型不能伪造人工操作，由隔离合成数据回归验证。公共安装包、真实新增生图及用户审美签收不在本次证明范围。

自动化回归覆盖 11 组、838 项：完整基线通过；集成后创作界面 131 项通过。分析组曾超过总运行器的 90 秒上限，独立复跑 98 项全部通过（123.839 秒）；其余未改动套件沿用完整基线结果。客户构建通过，RAG 22 个来源及版本一致。

## 当前边界与恢复

分析纠错与制作编排分别保存；修改分析不会自动覆盖已有分镜和图片，原制作方案按依据变化提示核对。对旧图的再采用仍需人明确选择。本次不宣称人物/场景生产资产的全部新增、删除和跨阶段迁移已实现；此后继续按同一原则审计。

未保存修改可恢复上次保存的方案，误删台词/镜头从已删除列表恢复。代码通过独立提交恢复；不要用删除创作数据库的方法回退。
