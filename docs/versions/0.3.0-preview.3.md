## 用户纠正与变化

用户指出风格探索混入被绑、受伤、居家等状态，且跳过了人物主多视图。新版将基础形象、主多视图、剧情状态明确分层，所有状态必须引用同一角色已确认主多视图。现有 MJ 图保留并可继续使用。历史状态图不自动升级为主图，审核和回执保留。

角色主档案自动出现在制作候选与缺项统计，不改写原剧本或 AI 方案。生成前与提交前验证来源，主图被退回会使下游结果待重新核对。前端两层独立草稿和明确按钮；镜头连续性提醒支持手工按行编辑。

## 验证

本地完整回归 664 项通过，其中分析 68、图片接入 64、创作界面 46；另含存储、授权、账号空间、任务、交付与集成回归。新增主图退回使下游失效、旧 MJ 候选供主图复用、同一档案不能同时充当主图和剧情状态的检查。RAG 索引 8 个来源有效，应用版本一致。全部自动回归使用合成图片与 provider，不代表真实图像质量通过。

真实 Chrome 前端已验证：风格页只显示基础形象，原已选 MJ 候选仍在；资产页默认“人物主多视图”；进入剧情状态后，未有已审核主图时生成按钮禁用，并提供“去制作人物主多视图”。已开始通过前端准备首张主多视图，实际返回与派生质量仍待验收。

## 恢复与限制

原运行实例不改动，本轮服务继续使用隔离实例数据。新版本保留旧图及任务记录；旧版不会执行新的人物主图依赖规则，不能回退后继续生成并声称符合当前产品要求。源码提交、CI、运行版本、真实图片审核、最终图文导出分别验收。
