## 具体变化

- DOCX 新项目入口补齐依赖，Chrome 原生文件选择框可正常导入。
- 剧本分析先保存并展示返回内容，逐条标红原文差异；显示对应原文、允许修改字段与关联人物／场景，支持采用原文。
- 保存人工修改不调用 AI，允许部分修正暂存，使用版本冲突检查。原结果与人工历史保留。旧记录可重新读取原回执，避免重复生成。
- 分析变化使原制作方案与交付范围待重新核对，避免把旧图当作新版完成。
- 导演台增加图文分镜 ZIP：HTML、镜头与原文台词 JSON、当前已审核的对应分镜图。缺图明确标记。
- 制作方案的核对入口直接可见，卡片详情不再被外层折叠遮住；按原文台词拆镜或手工加镜，提示对白时长，所有修改留在可保存草稿中。
- 同一物料不同状态可在前端选择沿用已选 MJ 形象，分别生成和审核 Image2，保持原图与不同状态之间的可追踪关系；不跨人物、账号或已变更设定借用。
- 修复参考图真实审核状态与任务快照字段不一致导致的 Image2 准备失败；失败原因可读，明确未提交的任务可在原位置取消，重新准备不复用已取消编号。
