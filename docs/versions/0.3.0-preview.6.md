## 需求与实现

用户强调简洁、美观和直接操作：部分功能点击图片即可选择，不要在每张图下面重复堆放按钮。

- 风格、资产、精修和分镜候选图点击后直接记录人工选用，仍调用既有审核接口并携带具体版本、文件摘要与档案版本。已选图片显示边框和勾选，不再次提交相同选择。
- 放大查看使用图片右上角独立按钮，仍进入原审核面板，可看原图和填写修改意见。图片按钮与放大按钮为平级原生按钮，支持键盘，并有明确中文名称。
- 全剧风格影响后续全部资产，继续使用独立的“选为本剧风格”及规范确认操作。分镜总览里的图片仍点击放大，不会因浏览已完成剧情而改变审核状态。
- 缩略图加载失败时停用图片选用入口，提示从右上角查看原图；失效历史不显示为当前已选，历史版本仍可放大对照。后台刷新保留当前选择禁用条件。
- 主按钮统一为暖白底、深色文字、细阴影和圆角；辅助操作更轻，生成/重抽使用小图标区分。候选卡片图片优先，物料列表、当前步骤和已确认风格统一层级，小屏图片单列展示。

## 验证与边界

本轮补齐覆盖如下，避免把“生成候选区已改”误说成所有入口已经统一：

| 入口 | 交互 |
| --- | --- |
| 基础形象、人物主多视图、精修原图、旧版制作表单的参考 | 原生单选图片卡，表单继续提交原 sourceRevisionId |
| 项目补充参考 | 图片多选，再点移除，每张图单独设定用途，最多 19 张 |

| LibTV 素材详情 | 点击具体图片复制为项目参考；目录按名称进入，导入后仍确认项目中的固定版本 |
| 导演镜头参考版本 | 点击缩略图固定具体 revisionId，保留取消固定和状态切换 |
| 导演文字引用弹层 | 显示可用的已审核图片，点选时绑定物料/状态/版本；未制图物料仍允许先编排文字 |
| 旧档案关联 | 点图确认档案适用性，不自动批准其中历史图片 |
| 旧任务返回区、集中审核列表 | 复用候选图的点击保留入口及独立放大入口 |
