# 0.3.0-preview.4

状态：开发与真实前端验收中。更新：2026-11-02。安装包、更新源与客户升级未验收；完整图文分镜目标继续进行。

## 当前实现

图片模型来自官方实时目录，默认 Lib Image 2.5 Pro；真实前端可见 28 个图片模型及 Pro 质量、分辨率、画幅等参数。MJ 主要探索人物、场景风格，正式资产默认 Pro；人物主多视图确认后才派生状态。实际模型、参数、原账号与参考版本写入不可变任务快照。

同一物料支持 1 至 8 组抽卡；导演台也可批量准备最多 8 个缺图镜头。跨镜头逐镜使用各自已保存提示词与固定参考，跳过已有任务、已有图片和参考未齐的镜头。确认清单后最多 3 个请求并发提交，独立保留回执；失败或未知结果不会自动重抽。准备任务不会覆盖未保存的镜头编辑。

本项目已审核图片可按用途补充参考，本地上传图单独保存、审核。LibTV 个人素材库支持搜索、预览、固定版本复制到项目，保留原库内容。团队素材库和完整分页仍未接通。视频、音频按用户要求后续接入。

静帧默认要求同时包含已保存构图、首帧状态和连续性，不提前加入镜末状态；已准备任务与手工草稿不改写。

导演台提供图文分镜直接预览与 ZIP 下载，二者共享当前快照、来源与图片哈希核验；只使用当前方案有效且已审核的分镜图。预览内嵌图片，可在浏览器查看和打印。误加空白镜头可删除并整理编号，其他镜头内容保留。

新客户端默认自动检查/下载更新，固定官方源并核对大小与 SHA-256，拒绝降级。安装前保存草稿并检查运行任务，独立辅助进程等旧进程退出后安装。Windows 成功后重开，Mac 交给系统安装窗口。旧客户端需先覆盖安装一次；源码运行不执行安装；独立 ManjuWorkbench 不混用更新源。打包客户端默认开放逐批确认的图片制作，仍须官方创作授权。

## 已核验证据

- 完整本地回归 719 项：716 通过、3 项原有跳过；覆盖本地存储、HTTP、模型契约、账号隔离、参考依赖、并发调度与更新流程。更新器 7 项、更新 HTTP 门禁 1 项。RAG 12 个来源校验通过。
- Chrome 前端已读取 28 个模型和 Pro 参数，并完成个人素材库图片预览、固定版本复制及看图保留。
- 同镜两组 Pro（high / 2K / 9:16，每组 1 张）均返回 1152×2048 图片；逐图检查身份、服装、手部和情绪构图后选用一版，另一版保留历史。这只证明该镜头的两次成功。
- 空仓库四视图由原任务恢复并审核，在导演台固定到 13 个相关镜头；22 镜编排已保存。前端预览已显示 22 镜与 1 张已审核分镜图，内嵌图片正常显示。
- 跨镜头一批 8 镜经前端准备和确认后，全部获得官方排队回执，图片正在陆续返回。逐镜复核已发现一张坐具与束缚位置不符，撤回测试选用并保存具体返修意见；继续检查其余画面。
- 火场 Pro 四格图与匕首白底图已返回并经前端测试选用；火场俯视通道存在细节偏差，已记录在审核意见中，后续镜头以正反打门窗为准。

真实预检发现的官方 Node → Image 引用显示转换已修复，只按已核验的节点和图片顺序比较，正文、来源与参数仍严格核对。未记录收费调用的中断任务可只读核实后显式重新准备。SSE keepalive 不再无限延长等待期限；未知收费回执始终恢复原请求。
