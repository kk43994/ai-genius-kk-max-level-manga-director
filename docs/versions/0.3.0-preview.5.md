状态：用户已授权公开发布，正在构建和验证。日期：2026-11-02。

继承 preview.4 已完成的真实前端 22 镜图片创作与图文脚本验收。新增右上方新版本浮动通知，下载校验通过后提供保存并安装，支持稍后提醒；不自动强制退出，不跳过草稿和任务检查。手动检查可重新显示本次已隐藏的版本；页面关闭后不保留隐藏状态。

安装包签名状态沿用预览版：Windows 未代码签名，Mac ad-hoc 签名且未公证。Windows 实机安装、系统覆盖安装与用户电脑实际提示尚未验收；公共源发布、下载校验与设备已升级分别记录。
