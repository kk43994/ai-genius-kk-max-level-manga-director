## 为什么改

用户要求整体检查；手机截图显示导航箭头变成蓝色 Emoji，主视觉顶部黑边偏多，英文贴在图像边缘。实际操作发现暂停会将相机缩放归零；此前章节高亮只更新不可见的旧导航。用户进一步要求替换中间的普通 KK，参考 LibTV / Lovart 的简洁识别感设计原创标识。

## 这次改了什么

- 原创 Frame K 胶片标识统一页头、中枢和浏览器图标；手机首屏上移画面，矢量箭头保持一致，补上可收起菜单与章节高亮。
- imagegen 并发探索独立图标与横向字标，保留原始透明 PNG 和提示词；最终界面使用经过几何整理的 SVG，便于小尺寸清晰显示。不是第三方平台 Logo 变体。
- 动画暂停保留当前构图；暂停、后台和主视觉完全离屏时不再持续安排绘制，恢复或浏览器返回时保持单一循环。系统减少动态效果优先，保留用户主动暂停。
- 入场动画改为可退化增强，缺少动画 API 或观察器时内容仍可读。菜单支持 Escape、选择后关闭与焦点返回；提高说明文字字号。
- 点击下载在当前视口显示请求提示；样式与脚本带内容指纹，避免浏览器混用上版缓存。安装包及更新源保持 preview.5。
