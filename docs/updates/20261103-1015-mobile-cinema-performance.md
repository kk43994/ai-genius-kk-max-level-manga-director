## 为什么改

用户反馈手机首屏动画明显卡顿。旧版在窄屏仍逐帧更新多个 SVG 图像裁切层、模糊扫光及动态光圈；相同章节文字每帧重写也持续触发布局。不能仅缩小桌面画面后称为手机适配。

## 这次改了什么

- 手机与触屏首屏改用轻量图像合成，保留黑金画面、呼吸光影和滑动推镜；停止操作后结束持续脚本循环。
- 轻量路径不运行 SVG 图像裁切、模糊扫光、噪点与多边形重画；环境动效只改变 transform/opacity，触屏横屏同样采用轻量路径。
- 同尺寸首屏图片编码为 242,314 字节 WebP，预加载和两套渲染共用 URL。原始 PNG 保留，未重新生成或改构图。
- 只在值变化时修改章节文字与样式，暂停保留镜头；后台、离屏和页面历史切换仍停播/恢复，系统减少动态效果优先。
- 独立工作目录隔离官网性能修复，避免夹带同时进行的导演台产品改动；网站更新不改变公开 preview.5 安装包与更新清单。

## 验证记录

- [x] 8 项动效状态回归，包括手机静止停止 RAF、滑动后收敛、SVG 不再重画、暂停保持、离屏/后台停播、触屏及桌面切换。
- [x] 3 项下载渲染检查，包含 WebP 文件有效性、350 KB 预算、真实安装包版本保留及更新资源指纹。
- [x] Chrome 390×844，4 倍 CPU 降速：旧版静止 31.698824 秒，1,863 次布局和样式重算，TaskDuration 13.862070 秒；新版静止 47.359567 秒，0 次新增布局/样式重算，ScriptDuration 增量 0，TaskDuration 0.624303 秒。按每秒归一化主线程占用约下降 97%；并非真实手机帧率测试。
- [x] 320 / 390 px 及 844 px 触屏横屏无横向溢出，手机轻量路径生效；实际前端滑动出现 DOLLY IN，暂停保持构图。
- [x] 桌面 1440 px 恢复完整 SVG 胶卷；系统减少动效显示“已减少动效”并禁用持续动画。Chrome 页面无脚本错误。
- [ ] GitHub CI、公开部署和 HTTPS 内容核验。
