# 资产研究室 · 客户网页版

独立开发基线，版本 `0.1.0-baseline`。客户最终通过网址使用，浏览器完成 LibTV 官方授权；不要求客户安装 Codex 或 CLI。发布目标服务器为用户指定的 `ssh kelao`，发布实施由第 9 会话负责。

## 开发预览

开发者需要 Python 3.10 或更新版本，无需安装第三方依赖：

```sh
python3 -m backend.app --port 8870
```

打开 <http://127.0.0.1:8870/>。服务仅绑定本机；8768 保留给原工作台。

本提交显示原资产研究室页面及合成空白数据。所有写入、授权和生成请求返回 `501 NOT_IMPLEMENTED`，页面底部明确标注基线状态。此阶段不保存客户项目，不读取本机账号，不运行后台生成线程，不代表客户功能已经完成。浏览器原页面自己的草稿逻辑仍在，后续需按租户隔离。

## 目录

- `frontend/`：从原资产研究室显式白名单复制的 HTML、JS、CSS。
- `backend/app.py`：可运行的离线基线入口；后续仅由集成会话接入各模块。
- `backend/legacy/`：迁移参考源码，原后端及其本地模块依赖；入口绝不导入。它仍含项目特定路径和 CLI 全局凭据假设，不能直接作为客户服务启动。
- `examples/blank-project.json`：纯合成空白样例。
- `docs/source-inventory.json`：来源路径、复制时 SHA-256 与字节数。
- `docs/`：接口、模块分工及官方接入核验。
- `work/`：忽略版本控制的中间文件；`outputs/`：忽略版本控制的交付报告。

不复制原 manifest、账号配置、凭据、客户剧本、生成媒体、执行历史。原后端内延迟导入的 Pillow / NumPy 只属于迁移参考；其安装和可选图像处理测试由相关模块会话明确锁定依赖。本预览不需要它们。未包含视频工程、渲染器、旧项目数据，因此不能直接运行 legacy 的项目特定视频/白模分支。

## 协作与数据

从本仓库的已提交基线创建独立工作副本，不在用户主目录的 Git 中工作。各模块约定见 `docs/module-ownership.md` 和 `docs/api-contract.md`。运行数据必须配置到发布代码之外的 `ASSET_LAB_DATA_DIR`；发布和刷新升级应保留客户项目、素材、授权与未完成任务。示例 `.env.example` 只用于解释配置，不包含真实域名或凭据，也不被此离线入口自动读取。

正式视频生成保持暂停；本轮不得提交任何收费任务。官方远程接入是否满足独立网站需求，以 `docs/libtv-official-evidence.md` 的实际证据为准。
